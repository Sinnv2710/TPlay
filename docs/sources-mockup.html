6 · Filters sheet. The two switches are there for every source and apply at once, with no reload. Show adult titles is the same switch as in Settings: it hides the genre "18+" where a site has one, and titles containing the source's adultWords where it does not. A source with genre, year, quality, rating or sort filters shows those groups below the switches.

What a source file looks like (example, dummy site)

// source definition: no code, only where to look
{
  "id": "table-site", "name": "Table Site", "version": 2,
  "site": "https://table-site.test",
  "list": {
    "path":      "/search/{keyword}/{page}/",
    "emptyPath": "/browse/{page}/",   // used when the search box is empty
    "card": "table.list tr:has(td.name)",
    "next": "div.pager a:contains(>>)",
    "infoLabel": "seeds",
    "fields": { "title": "td.name a[href^=/t/]", "year": "td.name a[href^=/t/]",
                "link": "td.name a[href^=/t/]@href", "info": "td.seeds" }
  },
  "filters": [],   // or { "name": "Genre", "param": "genre", "options": [...], "labels": {...} }
  "detail": {
    "release": "body",
    "fields": { "name": "h1", "size": "li:has(strong:containsOwn(Size)) span",
                "seeds": "span.seeds", "magnet": "a[href^=magnet:]@href" }
  },
  "adultWords": ["erotica", "xxx", "adult"]
}
// repository index (an address you paste in Sources)
{ "name": "My sources", "sources": [ { "id": "table-site", "name": "Table Site", "version": 2,
    "url": "https://raw.example.test/me/table-site.json" } ] }
Rules the app enforces
  • Repository and site addresses must be https.
  • A file is checked before it is accepted: id, name, selectors, required fields, size limits.
  • A source can only read pages of its own site, never your tokens or other apps.
  • Where to keep files: paste or pick a file on the phone, or host them anywhere public (gist, repo, static site).
Decisions taken
  • Sources lives under the Discover source picker, not Settings.
  • The YTS site stays as the one built-in source.
  • Self test is a manual button; the dot also updates every time a list loads.
  • Any https repository address is accepted.
  • Sites that need real code (logins, scripts) are skipped for now; a built-in Kotlin source can come later.
